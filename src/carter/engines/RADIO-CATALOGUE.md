# Radio catalogue

The static catalogue contains 117 tracks across 23 artists. Album/release names and durations are supplied display and simulation metadata; they are not claimed to be verified release data. Durations are integer milliseconds, converted from the supplied minutes and seconds. Tom Walker's “Wait for You” uses the requested 3:30 placeholder; all five Mohiner Ghoraguli entries use the placeholder release “Selected Songs (Placeholder)” and the requested placeholder durations. These placeholders are for simulation, not claims about actual releases.

All 23 artists use the user-supplied local artist photographs in `public/assets/carter/radio-artists/`; every track by an artist uses the same photograph. Existing `source` and `metadataSourceUrl` fields describe prior source matches, not independent verification of the current album or timing values. Rights to redistribute previously cached artwork have not been independently established.

The radio is a local, visual-only simulation with no audio or radio service connection. The selected duration drives progress, tonearm position and automatic selection of the next track. Refresh selects a new catalogue track without resetting the simulated station uptime.
