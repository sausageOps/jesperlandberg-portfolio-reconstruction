# ReframeHK + A24 navigation — implementation and QA

## Scope and source

The active Jesper foundation is the host. The separately checked-out ReframeHK project at `/home/user/reframehk-reconstruction` is the reference; its tracked source files were not changed. This report supersedes the previous report's Jesper-project integration: the latest requested scope explicitly removes that standalone portfolio.

The home route mounts the adapted ReframeHK engine and original field assets, with its original top HUD **alongside** the existing A24 navigation. The original animated wordmark/aperture button, Services/Work/Contact flights and cycling Work count, sound pill/EQ, and bottom hints, coordinates and Hong Kong clock are restored from source. The invented Field controls panel and added shortcuts were removed. The A24 menus, motion, route definitions and internal pages remain in place. Life/A24 logo also returns to the hero. The source sheet closes with a right/bottom slide and backdrop fade, not a camera flight.

The source checkout is GitHub `main` commit `1433343ab1152c8ed90f4460a7bc6379e291ca61`, verified against the remote. A search of its HTML, styles, scripts and README found no ellipsis menu or hidden menu options. On narrow screens the source hides the Sound label, leaving four tiny equalizer bars; this is the apparent ellipsis in the screenshot. It is the actual sound toggle, not an invented menu.

## Loading and field

The reference does not have a separate conventional progress preloader: its actual startup is an ink stage, distance-staggered tile reveal, and the animated aperture/wordmark assembly. The source timings, canvas drawings, layout packer, shaders, GSAP timelines, camera wrapping/flight/drag/wheel/fling, video behavior and Reframe project/contact sheets remain in `src/reframe/engine.js`. Reduced motion follows the source behavior. No Jesper loader or homepage is mounted or loaded. The A24 navigation still runs **its own** existing loading-word/reveal and route animations, as required to preserve that navigation; this is not the removed Jesper page loader. The navigation now waits for fonts rather than the deleted Jesper project textures/models.

Lifecycle changes scope field CSS variables and DOM to its React island and clean up its listeners, timelines, video, textures and renderer on route changes. Integration safeguards keep field shortcuts out of the A24 menu, cancel stale delayed Contact openings, restore sheet focus to the previously focused element and prevent focus escaping during the opening animation. These are adaptations, not claims of identical navigation behavior.

## Corrections following the source audit

- **No WebGL:** the fallback stays in the host's inner scroller to retain wheel/touch scrolling and keep A24 fixed. When initial focus is on the document, PageDown, PageUp, End, Home, vertical arrows and Space are forwarded to that scroller; focused controls and an open A24 menu retain their keys. The listener is removed on unmount. This is a necessary integration adaptation: the reference scrolls the document itself.
- **HUD keyboard:** arrows work when any original Reframe top-HUD button is focused, as in the source, without taking arrows/Escape away from A24 navigation or other interactive controls.
- **No JavaScript:** the source Fraunces accent, Space Mono HK border/sizing and original font/spacing rules are restored. The no-JS overrides also defeat the production bundle's fixed-body CSS, hide the empty React root, restore link underlines and allow document scrolling.
- **Blocked entry:** the original semantic index is in `index.html` outside the root instead of inside `<noscript>`; it remains accessible when the JS entry fails, and React hides it only after mounting so the live index is not duplicated. It remains visually clipped with JS enabled, as in the source; this is not a visible script-error page.
- **Audit follow-up:** imported the original self-contained GSAP bundle instead of sharing the host package; the source/target bundle SHA-256 is `0fe741a32f7e5ebbf127c4228f56bf2f5227c1629dc2541e14a96e379e74d3d5`, and browser checks confirmed different GSAP objects and tickers. Restored source absolute OG/Twitter image URLs. A home-only <320px rule removes the inherited 320px minimum and reduces flight-pill padding; at 280px both docks are hittable rather than clipping Sound as the source does. At 320px and above the source HUD sizing remains unchanged.

## Remaining differences and limits

A24 remains an additional navigation layer; the bottom HUD is raised above its mobile dock, and at 992–1080px the Reframe flight controls move down 48px to avoid the centered A24 dock. Modal stacking, route lifecycle and return-to-home behavior also differ from the standalone source. Several existing A24 pages are placeholders as noted above. The source canonical, OG URLs, structured data and `noindex, nofollow` are deliberately unchanged; set and verify deployment-specific identity and indexing only once the real host/domain is known. Physical iOS/Android, Safari and Firefox, audio fidelity, GPU performance, every repeated decorative field tile, every internal-page interaction, real social previews and exact normal-motion frame timing were not independently verified. CJK glyph appearance depends on device fallback fonts; this Linux test environment displayed missing-glyph boxes in some canvas text. Third-party asset and font republication rights have not been independently verified.
